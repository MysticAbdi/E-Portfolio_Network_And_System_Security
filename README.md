# Network & System Security - E-Portfolio

This repository contains a Networks and Systems Security e-portfolio.
It is organised as a weekly log of practical work carried out in labs and seminars,
using Python, Jupyter notebooks, and common security tools.

The portfolio covers:

- CIA triad and incident analysis
- Hybrid encryption (RSA + AES) over TCP sockets
- Authentication and access control (password strength, bcrypt, TOTP 2FA)
- Malware and file integrity monitoring (hashing, signatures, worm simulation)
- Web security and black-box scanning with Wapiti
- Static binary analysis (hashes, strings, PE headers, YARA)
- Basic penetration testing (recon, HTTP header analysis, port scanning)
- Portfolio review and alignment of lab documentation with implemented code
- Gen AI security using local LLMs and Ollama (prompt injection, model behaviour and risks)

## Weekly overview

- Week 01 - Foundations of Computer Security  
  CIA triad and mapping real incidents to confidentiality, integrity, and availability.

- Week 02 - RSA and Secure Messaging  
  Hybrid encryption demo that uses RSA for key exchange and AES for message confidentiality over TCP.

- Week 03 - Authentication and Access Control  
  Password strength evaluation, bcrypt hashing with salt and pepper, and TOTP based two factor authentication.

- Week 04 - Malicious Software and File Integrity  
  File integrity baselines with SHA-256, change detection, signature scanning, and a simple worm simulation.

- Week 05 - Web Security and Wapiti  
  Running a Wapiti black-box scan against a test web application and opening the HTML report.

- Week 06 - Static Binary Analysis  
  Hashing PE files, extracting printable strings, inspecting PE headers, and applying YARA rules.

- Week 07 - Penetration Testing Basics  
  Reconnaissance, HTTP header analysis, and a simple port scanner.

- Week 08 - Portfolio Review and Feedback  
  Reviewing the e-portfolio, adding the missing Week 1 careers task.

- Week 09 - Gen AI Security with Local LLMs  
  Running local language models with Ollama and exploring Gen AI security topics such as prompt injection, session level data poisoning concepts, model inversion style probing, and model extraction behaviour across multiple models.
