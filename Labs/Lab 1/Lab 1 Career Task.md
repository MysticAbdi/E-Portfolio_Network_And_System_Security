### Summary of main gaps and actions

From this activity I learned that:

- All three software engineering roles expect strong programming skills plus soft skills like communication, teamwork and attention to detail.
- I already have interest in software development and a basic foundation from my degree, but I lack real industry experience and practice with production tools such as cloud platforms, containerisation and modern front end frameworks.
- To move closer to these roles I need to deepen my knowledge of at least one main language, build more complete projects, learn some modern tools (for example React, TypeScript, Docker and AWS) and look for internships or junior roles that give me experience working in a team on real products.
