# Lab 1 - CIA Triad and Incident Analysis - Reflection

This week mainly focused on the mindset part of security rather than tools or code.
Working through real incidents forced me to move beyond memorising the CIA definitions and to actually apply them.

The main thing I learned is that impact is often messy in the real world.
A ransomware attack might look like an availability problem at first, but it also damages integrity and trust if backups are unreliable or if recovery is incomplete.
When I read about new incidents in the news I now automatically think about which CIA properties were affected and what could have prevented it.

This way of thinking will be useful later when I build or test systems.
For example, when I write cryptography code I will connect it back to confidentiality and integrity, and when I work with network services I will think more carefully about availability and resilience.
