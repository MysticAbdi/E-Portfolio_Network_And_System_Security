# Lab 5 - Web Security and Wapiti - Reflection

This lab was useful for seeing a real tool rather than only reading about web vulnerabilities.
Running Wapiti against a test target showed how quickly a scanner can send many requests and identify obvious problems.

At the same time, reading the report made it clear that human judgement is still required.
For each issue I had to think about whether it was actually exploitable, what business impact it would have, and how to fix it.
Tools cannot fully understand the context of an application.

In future, if I take part in a web assessment, I will expect to combine automated scanning with manual exploration and code review.
The experience with Wapiti gives me a starting point for understanding how commercial scanners and DAST tools fit into a wider security process.
